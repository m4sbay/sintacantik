## Validasi

- Dibandingkan dengan salinan sumber sebelum tugas: semua field pertanyaan, opsi (termasuk label sumber), kunci, nomor, urutan, modul, dan metadata gambar identik setelah field pembahasan dikecualikan.
- Total tetap 355; gambar tetap dua: Konservasi 21 dan Radiologi Dental 19.
- `npm run generate:questions`: lulus; 355 TRY OUT dan 60 Ortho tetap terpisah. Peringatan label opsi duplikat Konservasi 2 merupakan kondisi sumber yang tetap dipertahankan.
- `npm run lint`, `npm run typecheck`, `npm run build`: lulus.
- `npm test`: 51 tes pada 4 file lulus. Komponen review dirender untuk semua 355 soal pada masing-masing status benar, salah, dan tidak dijawab (1.065 kombinasi), memastikan bagian pembahasan tersedia dan fallback tidak muncul. Verifikasi ini merupakan pengujian render komponen, bukan uji klik browser.
- Tidak ada perubahan konfigurasi untuk meloloskan pemeriksaan.

## File pendukung yang diperbarui dalam tugas ini

- `src/data/tryout-questions.ts`: hasil generator dengan pembahasan.
- `scripts/parse-tryout.test.mjs`: fixture tanpa pembahasan untuk tetap menguji field opsional setelah seluruh sumber terisi.
- `src/lib/question-explanation.test.ts`: cakupan render semua soal TRY OUT pada tiga status.
- `README.md`: status ketersediaan pembahasan.
- Dokumen ini: rekap dan catatan review.
